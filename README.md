# コラージュ作成アプリ

選択した写真をInstagramストーリー比率(1080×1920px, 9:16)のコラージュに自動レイアウトし、
その場でPNG/JPEGとして書き出せるWebアプリです。インストール不要、ブラウザだけで完結します。

## 主な機能

- 写真を最大15枚まで選択(クリック or ドラッグ&ドロップ)
- 枚数に応じて複数のレイアウト案から選択可能
- セルを長押ししてドラッグすると、写真同士を入れ替え可能
- 各写真はドラッグ・ホイール/ピンチで位置調整・拡大縮小してトリミング範囲を決められる
- セル間の余白・背景色・角丸など簡単な装飾
- PNG/JPEGを選んでダウンロード

## プライバシーについて(重要)

- **画像はこの端末内(ブラウザ)だけで処理されます。** サーバーへのアップロードや外部通信は
  一切発生しません。ネットワークタブを開いて確認しても、画像に関するリクエストは送信されません。
- **EXIFメタデータ(撮影日時・位置情報など)は書き出し時に自動的に失われます。**
  Canvasに描画してから画像として書き出す仕組み上の副作用として、元ファイルの位置情報などの
  メタデータは出力ファイルに引き継がれません。
- 依存ライブラリなし。すべて素のHTML/CSS/JavaScriptで実装しています。

## 使い方

1. 画像を最大15枚まで選択(クリックまたはドラッグ&ドロップ)
2. サムネイル一覧で不要な画像を削除、ドラッグで並び替え
3. 「配置パターンを選ぶ」に並ぶ図解サムネイルから好きなレイアウトをクリックして選択
4. 各セル内の画像はドラッグで位置調整、ホイール/ピンチで拡大縮小してトリミング範囲を決定。
   セルを長押ししてから動かすと、別のセルの画像と入れ替えられる
5. 必要であればセル間の余白・背景色・角丸を調整
6. 書き出し形式(PNG/JPEG)を選び、ダウンロードボタンで保存
